# 🤖 AI Trading Bot for MetaTrader 5 (MT5)

একটি উন্নত মাল্টি-এজেন্ট AI ট্রেডিং বট যা MetaTrader 5 এর সাথে একীভূত। এই বট বিভিন্ন বিশ্লেষণ কৌশল ব্যবহার করে স্বয়ংক্রিয় ট্রেডিং সিদ্ধান্ত নেয়।

## 🌟 বৈশিষ্ট্য

- **মাল্টি-এজেন্ট সিস্টেম**: ৫টি স্বাধীন এআই এজেন্ট সহ ভোটিং ভিত্তিক সিদ্ধান্ত গ্রহণ
- **উন্নত বিশ্লেষণ**:
  - 📊 টেকনিক্যাল এনালাইসিস (ট্রেন্ড সনাক্তকরণ)
  - 🔮 LSTM ভিত্তিক পূর্বাভাস
  - 🌊 লিকুইডিটি সুইপ সনাক্তকরণ (SMC)
  - 📈 ট্রান্সফর্মার মডেল প্যাটার্ন বিশ্লেষণ
  - 📰 মার্কেট সেন্টিমেন্ট বিশ্লেষণ
- **রিস্ক ম্যানেজমেন্ট**: ১% ঝুঁকি পদ্ধতি এবং অবস্থান আকার ক্যালকুলেশন
- **MT5 সংযোগ**: MetaTrader 5 এর সাথে সরাসরি লাইভ ট্রেডিং ইন্টিগ্রেশন
- **রিট্রাই লজিক**: বিফল অর্ডারের জন্য স্বয়ংক্রিয় পুনরায় চেষ্টা
- **ব্যাপক লগিং**: বিস্তারিত ট্রেডিং লগ এবং ডিবাগিং তথ্য
- **স্বাস্থ্য পরীক্ষা**: স্টার্টআপ এবং রানটাইম নির্ভরযোগ্যতা যাচাইকরণ

## 📋 সিস্টেম আর্কিটেকচার

```
┌─────────────────────────────────────────┐
│      main_bot.py (এন্ট্রি পয়েন্ট)      │
│  • লগিং সেটআপ                           │
│  • স্বাস্থ্য পরীক্ষা                      │
│  • প্রধান ট্রেডিং লুপ                    │
└────────────┬────────────────────────────┘
             │
             ├─→ VotingOrchestrator
             │   • এজেন্ট সমন্বয়
             │   • ভোট একত্রীকরণ
             │   • ট্রেড এক্সিকিউশন ট্রিগার
             │
             ├─→ MultiAgent System
             │   ├─ TechnicalAgent (Order Flow)
             │   ├─ PredictiveAgent (LSTM)
             │   ├─ LiquiditySweepVoter (SMC)
             │   ├─ TransformerAgent (AI প্যাটার্ন)
             │   └─ SentimentAgent (নিউজ)
             │
             ├─→ RiskManager
             │   └─ পজিশন সাইজ ক্যালকুলেশন
             │
             └─→ TradeExecutor
                 └─ MT5 অর্ডার সম্পাদন
```

## 🚀 শুরু করুন

### প্রয়োজনীয়তা

- Python 3.8+
- MetaTrader 5 টার্মিনাল (Windows/Linux)
- Exness ট্রেডিং অ্যাকাউন্ট বা ডেমো অ্যাকাউন্ট


## 📊 এজেন্ট বিবরণ

### ১. TechnicalAgent (অর্ডার ফ্লো)
- **উদ্দেশ্য**: প্রবণতা সনাক্তকরণ
- **পদ্ধতি**: সহজ মূল্য কর্ম এবং ক্যান্ডেল বিশ্লেষণ
- **দেখার মেয়াদ**: ৫০ ক্যান্ডেল (H1)

### २. PredictiveAgent (LSTM)
- **উদ্দেশ্য**: মূল্য পূর্বাভাস
- **পদ্ধতি**: LSTM রিকারেন্ট নিউরাল নেটওয়ার্ক
- **দেখার মেয়াদ**: ৬০ ক্যান্ডেল

### ३. LiquiditySweepVoter (SMC)
- **উদ্দেশ্য**: স্মার্ট মানি ধারণা এবং লিকুইডিটি সুইপ
- **পদ্ধতি**: সাপোর্ট/রেজিস্ট্যান্স ব্রেকআউট বিশ্লেষণ
- **দেখার মেয়াদ**: ৩০ ক্যান্ডেল

### ४. TransformerAgent (এআই প্যাটার্ন)
- **উদ্দেশ্য**: উন্নত বাজার প্যাটার্ন স্বীকৃতি
- **পদ্ধতি**: ট্রান্সফর্মার নিউরাল নেটওয়ার্ক
- **বিশ্লেষণ**:
  - প্রবণতা কাঠামো
  - মোমেন্টাম গতিশীলতা
  - ভোলাটিলিটি পরিমাপ
  - সাপোর্ট/রেজিস্ট্যান্স শক্তি

### ५. SentimentAgent
- **উদ্দেশ্য**: বাজার অনুভূতি এবং সংবাদ প্রভাব
- **পদ্ধতি**: সংবাদ ফিড বিশ্লেষণ
- **দেখার মেয়াদ**: ২০ ক্যান্ডেল

## 🎯 ভোটিং ব্যবস্থা

```
প্রতিটি এজেন্ট দেয়:
├─ ভোট: BULLISH (+1) | NEUTRAL (0) | BEARISH (-1)
├─ আত্মবিশ্বাস: 0-100%
└─ কারণ: স্পষ্ট ব্যাখ্যা

├─ ভোট সংখ্যা: BULLISH %, BEARISH %, NEUTRAL %
├─ থ্রেশহোল্ড পরীক্ষা (ডিফল্ট: ৬০%)
└─ চূড়ান্ত সিদ্ধান্ত: BUY | SELL | HOLD
```

## 💰 ঝুঁকি ব্যবস্থাপনা

```
অ্যাকাউন্ট ব্যালেন্স: $10,000
ঝুঁকি শতাংশ: ১%
সর্বাধিক হারানো: $100 প্রতি ট্রেড

উদাহরণ: XAUUSD
├─ বর্তমান মূল্য: $২০২৫
├─ স্টপ লস: $২০২৩ (পার্থক্য: $২)
└─ লট সাইজ = $100 / ($2 * 100) = ০.৫ লট
```
